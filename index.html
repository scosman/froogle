    Froogle

    A free web search engine that is one HTML file. No tracking, no ads, no accounts, no cookies. You can save the page and run it from your own computer.

    How it works

    Results come from Keenable, a web search API. There are two ways your search can reach them. Here is how your search reaches them. There are up to two ways your search can reach them, depending on how this copy of the page is hosted.

    • Direct. If a Keenable API key is available — one you saved in Settings, or one built into this copy of the page — your browser calls Keenable itself. Your query never reaches a Froogle server.
    • Shared. With no key, your query passes through Froogle's own thin proxy, which stores nothing and logs nothing, and forwards the search to Keenable.
    • No shared mode. This copy of Froogle has no proxy of its own to fall back on, so without a key it cannot search at all.
    • Shared. Some copies of Froogle are deployed with a thin proxy of their own, which stores nothing and logs nothing. Where there is one, a query with no key passes through it on its way to Keenable; where there is not, a key is required. This page cannot tell which kind of copy it is until a search without a key tries — so try one. If this copy has no proxy, the search will say so and ask you for a key.

    The mode in use is always shown at the bottom of every page.

    Privacy

    Froogle sets no cookies, runs no analytics, and includes no third-party code. Your query is kept in the part of the address after the #, which browsers never send to a server, so it appears in no access log, no CDN log, and no Referer header.

    An API key you save is held in your browser's local storage and is sent only to Keenable. Whoever hosts this page can see that the page was requested, never what was searched. Keenable sees the query, and in direct mode your IP address.
